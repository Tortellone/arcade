# Definizione di LIVELLO
Il LIVELLO rappresenta una livello del gioco. i livelli sono descritti in file con il nome **LIVELLO_[Nome livello].md**

## Caratteristiche del livello
**Larghezza": Larghezza in pixel
**Altezza": Altezza in pixel
**TipoBackground": Altezza in pixel

## Esempio del contenuto di un file livello.
Larghezza: 5000
Altezza: 1080
TipoBackground
